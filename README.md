# TÜBİTAK 2204-A: Uyarlanabilir Sulama

Geçmiş sulama ve mikroiklim verileriyle toprağın kuruma süresinin tahmini ve uyarlanabilir sulama (2204-A Lise Öğrencileri Araştırma Projeleri Yarışması 2026-2027).

## İçerik
- `2204-A/` proje belgeleri: plan, malzeme listesi, araştırma özeti, proje raporu, rehber
- `2204-A/KODLAR/esp32_hx711_loadcell/` ESP32 yazılımı (ağırlık, toprak nemi, DHT11, pompa ve fan kontrolü)
- `2204-A/KODLAR/loadcell_panel.html` Web Serial paneli (Chrome/Edge)
- `2204-A/KODLAR/Kap_Karti_Baglanti_Semasi.html` kap kartı bağlantı şeması
- `2204-A/KODLAR/Ilerleme_Raporu.html` ilerleme raporu

## Durum
Çalışan bir tek kap tezgâh prototipi vardır. Pompa/fan donanımı, kesintisiz kayıt ve veri toplama henüz yapılmadı. Ayrıntılar ilerleme raporunda.
